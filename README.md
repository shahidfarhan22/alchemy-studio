# [Store name TBD] — 3D-Printed Miniatures Store

An online store for a solo 3D-printing business: browse and buy ready-made miniatures, or request a custom print with a manual quote.

**Status:** early planning/scaffolding (M0). Not yet runnable — see `docs/progress.md` for current state.

## Stack

Next.js (TypeScript) frontend · ASP.NET Core 8 (C#) API · PostgreSQL · Razorpay payments. Full reasoning in [docs/technology-stack.md](docs/technology-stack.md).
